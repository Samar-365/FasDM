12 CORE SYSTEM & FUNCTIONAL MODULES
================================================================================

--------------------------------------------------------------------------------
MODULE 1: User Profile & Cryptographic Identity
--------------------------------------------------------------------------------
- Purpose: Manages local identity creation, profile data, and cryptographic key generation.
- Requirements: FR-1 (User Registration), FR-15 (Encryption)
- Key Components: src/components/ProfileSetup.tsx, src/services/crypto.ts, src/services/db.ts, src/App.tsx
- Status: COMPLETED ✅
- Specifications:
  * Username setup and avatar selection/custom color presets.
  * Web Crypto API P-256 ECDH Keypair generation (Public/Private keys).
  * Key Fingerprint generation via SHA-256 digest (e.g. ABCD-1234-EF56-7890).
  * Tab-isolated session management (`sessionStorage`). Fresh browser tabs launch directly at the initial Splash Screen landing page (`splash`), while reloaded tabs maintain their profile identity.

--------------------------------------------------------------------------------
MODULE 2: Local Device Discovery & Peer Scanning
--------------------------------------------------------------------------------
- Purpose: Discovers active nearby nodes across local transport mediums without internet.
- Requirements: FR-2 (Device Discovery)
- Key Components: src/components/PeerScanner.tsx, src/services/network.ts, src/components/Dashboard.tsx
- Status: COMPLETED ✅
- Specifications:
  * Automatic beacon discovery over Local Wi-Fi (LAN), Wi-Fi Direct, and Bluetooth.
  * Real-time DISCOVERY_BEACON and PEER_HELLO packet broadcast & reception.
  * Signal strength (RSSI in dBm) measurement and latency calculation (ms).
  * Dynamic list of discovered and connected peer devices within < 5 seconds.
  * Single-tab simulated peer node generator for multi-device testing.
  * **Unread Notification Highlights**: Peers with unread messages are highlighted in Nearby Devices with glowing rose borders (`border-2 border-rose-500 shadow-[0_0_20px_rgba(244,63,94,0.4)] animate-pulse`), floating top notification badges (`🔔 Unread Message!`), and highlighted action buttons (`● Unread Message — Start P2P Chat`).
  * **Tab Notification Badges**: Animated `🔔 N New` unread badges on "Nearby Devices" and "Direct P2P Chat" dashboard tab buttons.
  * **Instant Clearance**: Notification highlights clear automatically right after the respective peer chat room is opened.

--------------------------------------------------------------------------------
MODULE 3: QR Code Pairing & Identity Verification
--------------------------------------------------------------------------------
- Purpose: Facilitates secure out-of-band device pairing via optical QR codes.
- Requirements: FR-3 (QR Pairing)
- Key Components: src/components/Dashboard.tsx (QR Modal), src/services/crypto.ts
- Status: COMPLETED ✅
- Specifications:
  * Dynamic QR Code generation embedding Device ID, Username, Public Key, and Fingerprint.
  * Identity display modal for peer scanning and out-of-band optical pairing.

--------------------------------------------------------------------------------
MODULE 4: One-to-One Encrypted P2P Messaging
--------------------------------------------------------------------------------
- Purpose: Handles direct peer-to-peer message transmission with end-to-end encryption.
- Requirements: FR-4 (One-to-One Messaging), FR-15 (Encryption)
- Key Components: src/components/ChatRoom.tsx, src/services/network.ts
- Status: COMPLETED ✅
- Specifications:
  * Direct 1-to-1 text, link, and emoji message exchange.
  * ECDH shared secret derivation combined with AES-GCM-256 payload encryption.
  * Random 12-byte Initialization Vector (IV) generation per message packet.
  * In-memory and IndexedDB message pipeline (`messages` store).
  * Strict deduplication logic by `messageId` and `fileAttachment.fileId` to prevent duplicate message entries across tabs.

--------------------------------------------------------------------------------
MODULE 5: Message Status & Real-Time Indicators
--------------------------------------------------------------------------------
- Purpose: Provides delivery receipts, read confirmations, and typing state updates.
- Requirements: FR-8 (Read Receipts), FR-9 (Typing Indicator)
- Key Components: src/components/ChatRoom.tsx, src/services/network.ts
- Status: COMPLETED ✅
- Specifications:
  * Real-time message status indicators: Sent (single check), Delivered (double check), Read (cyan double check).
  * Network packet acknowledgments (MSG_ACK, MSG_READ).
  * Dynamic typing status indicator ("User is typing...").

--------------------------------------------------------------------------------
MODULE 6: Group Messaging & Administration
--------------------------------------------------------------------------------
- Purpose: Enables multi-user chat rooms and group management on local networks.
- Requirements: FR-5 (Group Messaging)
- Key Components: src/components/GroupChatRoom.tsx, src/services/network.ts, src/services/db.ts
- Status: COMPLETED ✅
- Specifications:
  * Group creation modal, group naming, topic description, and peer invitation checkboxes.
  * Group administrator privileges (member removal, admin badges, group deletion).
  * Group member leave action and member list modal.
  * Group encrypted packet distribution (GROUP_CREATE, GROUP_MESSAGE, GROUP_MEMBER_LEAVE, GROUP_DELETE).
  * Persistent group stores (`groups` and `group_messages`) in IndexedDB v2.
  * Automated simulated peer response workflow in groups containing test nodes.
  * Inline file attachment rendering matching ChatRoom dimensions (`120px` width, `80px` frame height).

--------------------------------------------------------------------------------
MODULE 7: Peer-to-Peer File Sharing Engine & Media Viewer
--------------------------------------------------------------------------------
- Purpose: Transfers media and documents directly between connected nodes with preview controls.
- Requirements: FR-6 (File Sharing)
- Key Components: src/components/FileViewerModal.tsx, src/components/ChatRoom.tsx, src/components/GroupChatRoom.tsx, src/services/network.ts, src/services/db.ts
- Status: COMPLETED ✅
- Specifications:
  * Support for PDF, PNG, JPG, MP4, ZIP, PPT, and DOCX files up to 25MB.
  * Base64 / ArrayBuffer P2P transmission over FILE_TRANSFER network packets.
  * Automatic transport escalation to Wi-Fi Direct for large file payloads (>5MB).
  * **Inline Compact Thumbnail Cards**: Sleek `120px` width, `80px` height inline file cards (`object-contain`, max `76px` image preview) to maintain neat chat timelines.
  * **3X Expanded Media Viewer**: Floating full view modal (`FileViewerModal.tsx`) sized at 3X scale (`900px` width, `85vh` max height, `460px` image/video preview frame).
  * Header download controls and close actions with 100% inline styles to bypass global CSS conflicts.
  * Packet payload deduplication reusing `messageId` to eliminate duplicate file deliveries across tabs.

--------------------------------------------------------------------------------
MODULE 8: Voice Notes & Audio Messaging
--------------------------------------------------------------------------------
- Purpose: Enables recording, transmitting, and playing voice messages offline across 1-to-1 and Group Hub mesh chats.
- Requirements: FR-7 (Voice Messages)
- Key Components: src/components/AudioRecorder.tsx, src/components/ChatRoom.tsx, src/components/GroupChatRoom.tsx, src/services/network.ts, src/services/db.ts, src/types/index.ts
- Status: COMPLETED ✅
- Submodules:
  * 8.1 Data Model & Types: `VoiceNote` interface (voiceId, durationMs, audioData base64, mimeType, fileSize), `ChatMessage.voiceNote`, `GroupMessage.voiceNote`, `VOICE_NOTE` and `VOICE_ACK` network packet types.
  * 8.2 MediaRecorder & Waveform Analyzer Engine: Browser `MediaRecorder` API (`audio/webm`, `audio/ogg`), real-time frequency data extraction via Web Audio API (`AudioContext`, `AnalyserNode`), and microphone permission handling.
  * 8.3 Voice Recording UI Component: Compact microphone trigger button in input bar, real-time live pulsating waveform visualizer, recording duration timer (MM:SS), cancel button, stop & preview button, and instant send.
  * 8.4 Inline Voice Note Audio Player: Sleek in-bubble custom audio player with play/pause controls, static acoustic waveform bar visualization, interactive seek progress bar, and dynamic elapsed/total duration timestamps.
  * 8.5 P2P Mesh Network Voice Transport: Broadcast payload distribution over `VOICE_NOTE` packets, direct 1-to-1 & Group Hub routing, simulated peer voice acknowledgments, and packet deduplication.
  * 8.6 Timeline & Storage Integration: Embedding voice messages seamlessly inside `ChatRoom.tsx` (1-to-1) and `GroupChatRoom.tsx` (Group Hub) timeline threads with full offline IndexedDB persistence.

MODULE 10: Shared Collaboration Tools
--------------------------------------------------------------------------------
- Purpose: Provides real-time internet-free collaborative workspace tools (Whiteboard, Checklist, Sticky Notes) within 1-to-1 and Group chats.
- Requirements: FR-11 (Shared Whiteboard), FR-12 (Shared Checklist), FR-13 (Shared Notes)
- Key Components: src/components/CollaborationHub.tsx, src/components/collaboration/SharedWhiteboard.tsx, src/components/collaboration/SharedChecklist.tsx, src/components/collaboration/SharedStickyNotes.tsx, src/services/collaborationSync.ts, src/services/network.ts, src/services/db.ts, src/types/collaboration.ts
- Status: COMPLETED ✅
- Submodules:
  * 10.1 Data Models, Action Types & Packet Protocol (`src/types/collaboration.ts`, `src/types/index.ts`):
    - Whiteboard Data Models: `DrawingStroke` (strokeId, points `[{x, y}]`, color, size, tool: 'pen' | 'brush' | 'eraser', authorId, timestamp), `CanvasSnapshot`.
    - Checklist Data Models: `ChecklistItem` (itemId, title, completed, createdBy, completedBy, priority: 'urgent' | 'high' | 'medium' | 'low', timestamp, orderIndex).
    - Sticky Notes Data Models: `StickyNote` (noteId, content, color, position `{x, y}`, zIndex, authorId, authorName, lastEditedBy, lastModified).
    - Mesh Packet Protocols: `COLLAB_WHITEBOARD_ACTION`, `COLLAB_CHECKLIST_ACTION`, `COLLAB_STICKY_ACTION`, `COLLAB_ROOM_STATE_REQUEST`, `COLLAB_ROOM_STATE_RESPONSE`, `COLLAB_PRESENCE_HEARTBEAT`.
  * 10.2 Collaboration Hub Workspace Container (`src/components/CollaborationHub.tsx`):
    - Multi-tool tab bar navigation (Whiteboard, Checklist, Sticky Notes) with badge indicators.
    - Scope toggle: Seamlessly switch between Direct 1-to-1 Peer workspace and Group Hub shared session.
    - Live Presence & Peer Avatar Bar: Displays active peer participants currently in the collaboration room.
    - Snapshot Export Controls: One-click export canvas to PNG image, export checklist/notes to Markdown/JSON.
  * 10.3 Real-Time Synchronized Whiteboard Canvas (`src/components/collaboration/SharedWhiteboard.tsx`):
    - HTML5 2D Canvas with normalized `[0.0, 1.0]` coordinate scaling for resolution-independent multi-device rendering.
    - Cyberpunk drawing toolbar: Neon color palette, variable brush sizes (2px-24px), highlighter mode, eraser, grid toggle.
    - Dynamic stroke smoothing (quadratic Bezier interpolation) and pointer movement throttle (~16ms batching).
    - Local & remote stroke streaming, real-time remote cursor indicators, undo/redo stack, and canvas clear confirmation modal.
  * 10.4 Interactive Multi-User Checklist Engine (`src/components/collaboration/SharedChecklist.tsx`):
    - Real-time task matrix with optimistic UI toggles and instant P2P state broadcast.
    - Task creation input bar with priority selectors, assignee tags, and due indicators.
    - Dynamic progress meter showing completion percentage (`% completed`, progress bar animation).
    - Multi-criteria filter & sort controls (All, Pending, Completed, Priority, Assignee).
  * 10.5 Freeform Collaborative Sticky Notes Board (`src/components/collaboration/SharedStickyNotes.tsx`):
    - Interactive 2D drag-and-drop workspace for movable sticky notes with boundary clipping.
    - Cyberpunk neon/pastel color palettes (Yellow, Cyan, Emerald, Rose, Purple, Slate).
    - Rich text inline editing with concurrency locking indicator (highlights when a peer is currently editing a note).
    - Add, duplicate, pin to top, and delete note actions with animated transitions.
  * 10.6 P2P State Synchronization & Conflict-Free Resolution (`src/services/collaborationSync.ts`):
    - State hydration handshake: `COLLAB_ROOM_STATE_REQUEST` -> `COLLAB_ROOM_STATE_RESPONSE` when opening a room.
    - Last-Write-Wins (LWW) deterministic conflict resolution using Lamport / microsecond timestamps.
    - Action deduplication cache (`actionId`) and state delta broadcast over mesh network.
    - Offline queueing & reconciliation when nodes disconnect and rejoin mesh range.
  * 10.7 IndexedDB Persistence & Chat Timeline Integration (`src/services/db.ts`, `src/components/ChatRoom.tsx`, `src/components/GroupChatRoom.tsx`):
    - IndexedDB stores (`collab_whiteboard`, `collab_checklists`, `collab_notes`) in schema v4 keyed by session ID (`peerId` or `groupId`).
    - Collaboration Hub trigger button in ChatRoom and GroupChatRoom header bars.
    - Offline state retrieval and persistence on device reload.

12 CORE SYSTEM & FUNCTIONAL MODULES
================================================================================

--------------------------------------------------------------------------------
MODULE 1: User Profile & Cryptographic Identity
--------------------------------------------------------------------------------
- Purpose: Manages local identity creation, profile data, and cryptographic key generation.
- Requirements: FR-1 (User Registration), FR-15 (Encryption)
- Key Components: src/components/ProfileSetup.tsx, src/services/crypto.ts, src/services/db.ts
- Status: COMPLETED ✅
- Specifications:
  * Username setup and avatar selection/custom color presets.
  * Web Crypto API P-256 ECDH Keypair generation (Public/Private keys).
  * Key Fingerprint generation via SHA-256 digest (e.g. ABCD-1234-EF56-7890).
  * Session isolation via sessionStorage and offline IndexedDB persistence.

--------------------------------------------------------------------------------
MODULE 2: Local Device Discovery & Peer Scanning
--------------------------------------------------------------------------------
- Purpose: Discovers active nearby nodes across local transport mediums without internet.
- Requirements: FR-2 (Device Discovery)
- Key Components: src/components/PeerScanner.tsx, src/services/network.ts
- Status: COMPLETED ✅
- Specifications:
  * Automatic beacon discovery over Local Wi-Fi (LAN), Wi-Fi Direct, and Bluetooth.
  * Real-time DISCOVERY_BEACON and PEER_HELLO packet broadcast & reception.
  * Signal strength (RSSI in dBm) measurement and latency calculation (ms).
  * Dynamic list of discovered and connected peer devices within < 5 seconds.
  * Single-tab simulated peer node generator for multi-device testing.

--------------------------------------------------------------------------------
MODULE 3: QR Code Pairing & Identity Verification
--------------------------------------------------------------------------------
- Purpose: Facilitates secure out-of-band device pairing via optical QR codes.
- Requirements: FR-3 (QR Pairing)
- Key Components: src/components/Dashboard.tsx (QR Modal), src/services/crypto.ts
- Status: COMPLETED ✅
- Specifications:
  * Dynamic QR Code generation embedding Device ID, Username, Public Key, and Fingerprint.
  * Identity display modal for peer scanning and out-of-band optical pairing.

--------------------------------------------------------------------------------
MODULE 4: One-to-One Encrypted P2P Messaging
--------------------------------------------------------------------------------
- Purpose: Handles direct peer-to-peer message transmission with end-to-end encryption.
- Requirements: FR-4 (One-to-One Messaging), FR-15 (Encryption)
- Key Components: src/components/ChatRoom.tsx, src/services/network.ts
- Status: COMPLETED ✅
- Specifications:
  * Direct 1-to-1 text, link, and emoji message exchange.
  * ECDH shared secret derivation combined with AES-GCM-256 payload encryption.
  * Random 12-byte Initialization Vector (IV) generation per message packet.
  * In-memory and IndexedDB message pipeline (`messages` store).

--------------------------------------------------------------------------------
MODULE 5: Message Status & Real-Time Indicators
--------------------------------------------------------------------------------
- Purpose: Provides delivery receipts, read confirmations, and typing state updates.
- Requirements: FR-8 (Read Receipts), FR-9 (Typing Indicator)
- Key Components: src/components/ChatRoom.tsx, src/services/network.ts
- Status: COMPLETED ✅
- Specifications:
  * Real-time message status indicators: Sent (single check), Delivered (double check), Read (cyan double check).
  * Network packet acknowledgments (MSG_ACK, MSG_READ).
  * Dynamic typing status indicator ("User is typing...").

--------------------------------------------------------------------------------
MODULE 6: Group Messaging & Administration
--------------------------------------------------------------------------------
- Purpose: Enables multi-user chat rooms and group management on local networks.
- Requirements: FR-5 (Group Messaging)
- Key Components: src/components/GroupChatRoom.tsx, src/services/network.ts, src/services/db.ts
- Status: COMPLETED ✅
- Specifications:
  * Group creation modal, group naming, topic description, and peer invitation checkboxes.
  * Group administrator privileges (member removal, admin badges, group deletion).
  * Group member leave action and member list modal.
  * Group encrypted packet distribution (GROUP_CREATE, GROUP_MESSAGE, GROUP_MEMBER_LEAVE, GROUP_DELETE).
  * Persistent group stores (`groups` and `group_messages`) in IndexedDB v2.
  * Automated simulated peer response workflow in groups containing test nodes.

--------------------------------------------------------------------------------
MODULE 7: Peer-to-Peer File Sharing Engine
--------------------------------------------------------------------------------
- Purpose: Transfers media and documents directly between connected nodes.
- Requirements: FR-6 (File Sharing)
- Key Components: src/components/FileViewerModal.tsx, src/services/network.ts, src/services/db.ts
- Status: PENDING ⏳ (Next Up for Implementation)
- Specifications:
  * Support for PDF, PNG, JPG, MP4, ZIP, PPT, and DOCX files up to 25MB.
  * Base64 / ArrayBuffer chunked P2P transmission over FILE_TRANSFER network packets.
  * Automatic transport escalation to Wi-Fi Direct for large file payloads (>5MB).
  * In-app file viewer preview and browser file download triggers.

--------------------------------------------------------------------------------
MODULE 8: Voice Notes & Audio Messaging
--------------------------------------------------------------------------------
- Purpose: Enables recording, transmitting, and playing voice messages offline.
- Requirements: FR-7 (Voice Messages)
- Key Components: src/components/AudioRecorder.tsx, src/components/ChatRoom.tsx, src/services/db.ts
- Status: PENDING ⏳ (Next Up for Implementation)
- Specifications:
  * Microphone capture using MediaRecorder API (audio/webm, audio/ogg).
  * Inline waveform/timer audio recorder component with Start, Stop, and Send buttons.
  * Inline audio player component with Play/Pause, timeline slider, and duration label.

--------------------------------------------------------------------------------
MODULE 9: Emergency Broadcast System
--------------------------------------------------------------------------------
- Purpose: Allows emergency coordinators or authorized users to broadcast instant alerts.
- Requirements: FR-10 (Broadcast Messaging)
- Key Components: src/components/EmergencyBroadcast.tsx, src/services/network.ts
- Status: PENDING ⏳
- Specifications:
  * Priority emergency alert composition with severity levels (Low, Medium, High, Critical).
  * High-priority notification push to all nearby reachable nodes simultaneously (EMERGENCY_ALERT packets).
  * High-contrast top emergency alert banner UI overlay across all views.

--------------------------------------------------------------------------------
MODULE 10: Shared Collaboration Tools
--------------------------------------------------------------------------------
- Purpose: Provides real-time internet-free collaborative workspace tools within chats.
- Requirements: FR-11 (Shared Whiteboard), FR-12 (Shared Checklist), FR-13 (Shared Notes)
- Key Components: src/components/CollaborationHub.tsx, src/services/network.ts
- Status: PENDING ⏳
- Specifications:
  * Shared Whiteboard: Synchronized HTML5 canvas with drawing, color picker, brush thickness, and eraser tools (WHITEBOARD_SYNC).
  * Shared Checklist: Interactive multi-user task list with add, toggle complete, and delete actions (CHECKLIST_SYNC).
  * Shared Sticky Notes: Synchronized moveable notes board for team brainstorming (NOTES_SYNC).

--------------------------------------------------------------------------------
MODULE 11: Local Storage Engine & Offline Persistence
--------------------------------------------------------------------------------
- Purpose: Manages persistent offline storage, caching, and database schemas.
- Requirements: FR-14 (Local Storage)
- Key Components: src/services/db.ts (IndexedDB Engine v2)
- Status: COMPLETED ✅
- Specifications:
  * IndexedDB Version 2 object stores: profile, peers, messages, groups, group_messages, files.
  * Storage quota estimation API and clear/reset user data controls.
  * Full offline operation with persistent state across app restarts and reboots.

--------------------------------------------------------------------------------
MODULE 12: Mesh Routing & Channel Auto-Selection
--------------------------------------------------------------------------------
- Purpose: Optimizes transport channel selection and enables multi-hop network routing.
- Requirements: FR-16 (Mesh Routing), FR-17 (Automatic Network Selection)
- Key Components: src/services/network.ts, src/services/meshRouter.ts
- Status: IN PROGRESS / COMPLETED FOR DIRECT TRANSPORT 🔄
- Specifications:
  * Automatic network selection by priority: Local LAN -> Wi-Fi Direct -> Bluetooth.
  * Dynamic channel switching based on throughput, latency, and payload size.
  * Multi-hop mesh routing overlay (Node A -> Node B -> Node C -> Node D) with TTL loop prevention.
